# RAG Document Analyzer

Q&A system for PDF documents using RAG (Retrieval Augmented Generation).

## Features (planned)
- PDF loading and validation
- Text chunking
- Semantic search
- Q&A with LLM
- Citations
- Chat interface

## Progress
- [x] Basic PDF loading
- [x] File validation
- [ ] Text chunking (next week)

## Setup
```bash
  pip install -r requirements.txt
```
